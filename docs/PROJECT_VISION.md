# Project Vision

## Что строим

`audio-practices` начинается как простая библиотека аудиопрактик, но версия `v2` закладывает основу личной платформы развития.

Платформа должна постепенно объединить:

- аудиопрактики;
- видео;
- статьи;
- программы и курсы;
- трекинг состояния и прогресса;
- избранное;
- рекомендации;
- ИИ-помощника.

## Главный принцип v2

Проект должен быть построен вокруг данных, а не вокруг файлов.

Файл аудио, видео или статьи - это только один из источников контента. Основной объект системы - практика: у нее есть название, описание, контекст применения, тип, медиа, теги и будущие связи с программами, прогрессом, избранным и рекомендациями.

## Что важно сохранить

- MVP уже работает, его не ломаем.
- На шаге v2.1 не создаем админку.
- Сначала описываем контент в коде как типизированные данные.
- Позже эти данные можно будет перенести в CMS, Supabase, базу данных или админку без полной переделки интерфейса.

## Ближайшая цель

Сделать так, чтобы главная страница читала практики из единого файла данных:

- `src/types/practice.ts` - типы;
- `src/data/practices.ts` - список практик и контекстов;
- `src/app/page.tsx` и `src/app/PracticePlayer.tsx` - отображение этих данных.

## Будущие возможности

После v2 архитектура должна позволить добавить:

- фильтры по контексту, длительности, типу и цели;
- отдельные страницы практик;
- пользовательский прогресс;
- избранное;
- рекомендации на основе истории;
- программы из нескольких практик;
- ИИ-помощника, который помогает выбрать практику под состояние пользователя.
